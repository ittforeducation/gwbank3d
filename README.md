# 地下水銀行 3D 探索：從潮州到彰化

國小六年級用的 3D 教具（three.js），從 `index.html` 進入。核心問題：彰化的滯洪池能不能效法潮州的大潮州人工湖，變成地下水銀行？

網址：https://ittforeducation.github.io/gwbank3d/

- 屏東篇 A1～A6：認識地下水銀行，歸納「補注四條件」
- 彰化篇 B1～B3：用四條件檢驗彰化的滯洪池，設計改造方案、寫建議卡
- 學習單（學生版）：`files/worksheet_student.pdf`

## 資料來源
- 地形：內政部 20 公尺網格數值地形模型（政府資料開放授權）
- 正射影像：國土測繪中心（政府資料開放授權）
- 河川、水圳、道路等向量資料：© OpenStreetMap 貢獻者（ODbL）
- 材質、天空：Poly Haven（CC0）
- 數字與說法的出處：經濟部水利署、中央地質調查所、《土木水利》48(6) 等，各站頁尾另附資料出處
- 動畫裡的數字（入滲量、指標等）是教學示意，不是實測或預測
